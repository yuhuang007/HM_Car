# Hi3861 串口诊断工具

当前脚本使用 Windows API 和 Python 标准库，不需要安装 `pyserial`。运行后按提示选择 COM 口，波特率为 `115200`。

```powershell
python serial_diag.py
```

## 诊断步骤

1. 先把 Hi3861 主板的 USB 线接到电脑（用于查看串口输出）
2. 运行脚本: python serial_diag.py
3. 观察输出的诊断报告

## 诊断结论解读

### 如果显示:
    [!] 超声波距离始终为 0 -> CS100A 模块可能未连接或未工作

原因:
  - CS100A 模块没有接到电机驱动板的 UART2 上
  - CS100A 模块没有上电
  - CS100A 固件没有正确运行

### 如果显示:
    [!] 无循迹数据 -> 光电管模块可能未连接或固件不支持

原因:
  - CS100A 模块上的光电管没有工作
  - 电机驱动板固件不支持接收 0xAA 帧

### 如果显示:
    [OK] 超声波有有效数据
    [OK] 循迹数据帧正在传输

说明模块工作正常，问题在控制逻辑上。
